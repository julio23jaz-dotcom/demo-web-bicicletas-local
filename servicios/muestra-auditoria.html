Hallazgos de ejemplo

PRIORIDAD ALTA · CONTACTO

El botón de correo apunta a un dominio reservado

El enlace “Escríbenos” abre mailto:demo@example.invalid. El dominio .invalid se usa como marcador y no permite recibir consultas, así que el contacto no está listo para una web real.

Recomendación: antes de publicar, sustituye el enlace por el correo real autorizado y prueba que abre el programa de correo con el destinatario correcto.

PRIORIDAD MEDIA · NAVEGACIÓN MÓVIL

El acceso a “Proyectos” desaparece en pantallas pequeñas

En la regla CSS para anchos de hasta 520 px, el tercer enlace de navegación se oculta. El contenido sigue en la página, pero el menú deja de ofrecer un acceso directo a esa sección.

Recomendación: conserva el enlace con un menú compacto o permite que la navegación se desplace a una segunda línea; verifica la solución a 320–390 px.

PRIORIDAD MEDIA · DATOS DE EJEMPLO

La ubicación y la trayectoria deben reemplazarse antes de usar la plantilla

La muestra incluye “Ginebra · Suiza” y “Est. 2018”. La página marca el contenido como ficticio, pero un comprador que adapte el diseño debe reemplazar esos datos para no publicar una ubicación o antigüedad incorrectas.

Recomendación: confirma ciudad, zona de atención y fechas con el negocio; elimina cualquier dato sin verificar antes de publicar.
